## Overview

This repository contains my actuarial science honours dissertation, together with its Python research code, dataset, LaTeX source files and supporting figures.

The research examines Bayesian networks as a framework for representing dependencies and investigating causal relationships among operational risk indicators. It explores how probabilistic modelling can support the assessment of operational losses, scenario analysis and risk mitigation decisions in financial institutions.

## Working With the Research Files

The code is preserved in its original notebook-oriented form and requires environment setup and compatibility checks before execution.

The original data-loading step references `/content/ORXData.xlsx`, while this repository includes `ORXData .csv`. Adapt the data-loading step to the supplied file format and location before reproducing the analysis.

The LaTeX manuscript starts at `main.tex` and uses Biber for its bibliography. Preserve the referenced chapter filenames and supporting image paths when working with the document.
